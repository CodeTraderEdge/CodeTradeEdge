### 💡 Principios de diseño

```
⚡  Idempotencia primero       →  cualquier operación debe poder repetirse sin efectos secundarios
🔭  Observabilidad desde día 1 →  trazas, métricas y logs no son un añadido, son parte del diseño
🛡️  Resiliencia sobre perfección→  DLQ, retries, circuit breakers antes de confiar en el happy path
📦  Bounded contexts claros    →  cada servicio conoce sus límites y respeta los ajenos
☁️  Serverless cuando aplica   →  FaaS y BaaS para reducir operación sin sacrificar escala
🔀  Async por defecto          →  sistemas desacoplados que escalan y fallan de forma independiente
```
